# Свадебное приглашение — Денис & Алиса

Перенос дизайна из Figma (кадр 430×2528) на Vite + React + TypeScript.
Анимации: вращение солнца (10 с), покадровый цикл котов (0,8 → 0,8 → 0,8 → 1,6 с, с сердечком в последнем кадре),
случайная пульсация яркости звёзд (на звёзды можно навести курсор или коснуться — они вспыхивают сильнее),
прелоадер: пока грузятся картинки и шрифты, показывается экран с «солнцем», затем страница раскрывается кругом из центра.

## Быстрый старт (1 раз, на своём компьютере)

Нужен Node.js 18+.

```bash
npm install
npm run fetch-assets   # скачает картинки из Figma в public/assets
npm run dev            # посмотреть на http://localhost:5173
```

**Важно:** ссылки на картинки в Figma живут 7 дней. После `npm run fetch-assets`
закоммитьте папку `public/assets` — тогда сайт больше не зависит от Figma.

## Деплой на Vercel

1. Залейте проект в GitHub (вместе с `public/assets`).
2. На vercel.com: **Add New → Project**, выберите репозиторий.
3. Vercel сам определит Vite. Ничего менять не нужно → **Deploy**.

Если забыли закоммитить `public/assets`, сборка попытается скачать картинки сама
(пока ссылки Figma не истекли).

## Если картинки уже скачаны

Файлы `cover-top.webp`, `cover-bottom.webp` (синие обложки с аркой, зерном и обводкой), `sep-1…4.png`
(золотые разделители) и `bg-grain.png` (зерно фона) уже лежат в `public/assets`: скачивать их не нужно.
Нижняя обложка обрезана ровно под длину сайта (кадр 430×2528). Остальное докачивает `npm run fetch-assets`
(или скопируйте свои старые файлы в `public/assets`).

## Что где лежит

- `src/App.tsx` — вся вёрстка, координаты взяты из Figma 1:1
- `src/styles.css` — шрифты, анимации солнца и котов
- `src/config.ts` — ссылка для кнопки «{ ОТКРЫТЬ МЕНЮ }» (`MENU_URL`) и минимальное время прелоадера (`PRELOADER_MIN_MS`)
- `src/Preloader.tsx`, `src/twinkle.ts` — прелоадер и пульсация звёзд
- `src/assets.ts` — список картинок, которые ждёт прелоадер
- `scripts/assets-manifest.json` — откуда качаются картинки
