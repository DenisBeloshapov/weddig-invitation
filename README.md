# Свадебное приглашение — Денис & Алиса

Перенос дизайна из Figma (кадр 430×2505) на Vite + React + TypeScript.
Анимации: вращение солнца (10 с), покадровый цикл котов (0,8 → 0,8 → 0,8 → 1,6 с, с сердечком в последнем кадре),
случайная пульсация яркости звёзд (на звёзды можно навести курсор или коснуться — они вспыхивают сильнее),
прелоадер: пока грузятся картинки и шрифты, показывается экран с «солнцем», затем страница раскрывается кругом из центра.

## Если сборка на Vercel падает: «Не удалось скачать … файл(ов)»

Ссылки Figma на картинки действуют только **7 дней**. Сборка скачивает картинки, пока они не лежат в репозитории,
поэтому через неделю она падает. Лечится один раз, навсегда: картинки должны лежать в репозитории (`public/assets`).

Способ без компьютера (GitHub Actions):
1. Положите в репозиторий обновлённые `scripts/assets-manifest.json`, `scripts/fetch-assets.mjs`
   и файл `.github/workflows/fetch-assets.yml`.
2. Файлы, у которых в манифесте стоит `null` (сейчас это `kiss-3.png`), экспортируйте из Figma вручную
   (слой в нужном варианте компонента → Export → PNG, 3x) и загрузите в `public/assets`.
3. GitHub → вкладка **Actions** → **Fetch Figma assets** → **Run workflow**. Картинки скачаются и сами
   закоммитятся в репозиторий, Vercel соберёт сайт заново. Делать это нужно, пока ссылки в манифесте свежие (7 дней).

Способ на компьютере: `npm run fetch-assets`, затем закоммитьте папку `public/assets`.

## Быстрый старт (1 раз, на своём компьютере)

Нужен Node.js 18+.

```bash
npm install
npm run fetch-assets   # скачает картинки из Figma в public/assets
npm run dev            # посмотреть на http://localhost:5173
```

**Важно:** ссылки на картинки в Figma живут 7 дней. После `npm run fetch-assets`
закоммитьте папку `public/assets` — тогда сайт больше не зависит от Figma.

## Деплой на Vercel

1. Залейте проект в GitHub (вместе с `public/assets`).
2. На vercel.com: **Add New → Project**, выберите репозиторий.
3. Vercel сам определит Vite. Ничего менять не нужно → **Deploy**.

Если забыли закоммитить `public/assets`, сборка попытается скачать картинки сама
(пока ссылки Figma не истекли).

## Если картинки уже скачаны

Файлы `cover-top.webp`, `cover-bottom.webp` (синие обложки с аркой, зерном и обводкой), `sep-1…5.png`
(золотые разделители) и `bg-grain.png` (зерно фона) уже лежат в `public/assets`: скачивать их не нужно.
Нижняя обложка обрезана ровно под длину сайта (кадр 430×2505). Остальное докачивает `npm run fetch-assets`
(или скопируйте свои старые файлы в `public/assets`).

## Страница меню

Кнопка «{ ОТКРЫТЬ МЕНЮ }» ведёт на страницу меню (адрес `ваш-сайт/#/menu`, настройки сервера не нужны).
Там пять сетов (Western A, B, C и Thai A, B) и форма выбора: ФИО того, кто заполняет, выбор сета
и основного блюда, возможность добавить выбор за другого гостя. Тексты меню лежат в `src/menuData.ts`.

**Отправка пока заглушка:** данные никуда не уходят, а сохраняются только в браузере гостя.
Когда подключим Google-таблицу, адрес нужно будет вписать в `src/config.ts` (`SHEET_WEBHOOK_URL`).

## Что где лежит

- `src/App.tsx` — вся вёрстка, координаты взяты из Figma 1:1
- `src/styles.css` — шрифты, анимации солнца и котов
- `src/config.ts` — адрес страницы меню (`MENU_URL`), время прелоадера (`PRELOADER_MIN_MS`), адрес таблицы (`SHEET_WEBHOOK_URL`)
- `src/App.tsx` — переходы между приглашением и меню; `src/Invitation.tsx` — приглашение; `src/MenuPage.tsx`, `src/menuData.ts`, `src/api.ts` — меню
- `src/Preloader.tsx`, `src/twinkle.ts` — прелоадер и пульсация звёзд
- `src/assets.ts` — список картинок, которые ждёт прелоадер
- `scripts/assets-manifest.json` — откуда качаются картинки
