# Ответы гостей в Google Таблицу

Сайт отправляет выбор меню в скрипт Google Apps Script, а тот дописывает строки в таблицу.
**Вся таблица на английском**, имена гостей записываются латиницей (транслитерация: «Иванов Иван» → «Ivanov Ivan»).
Каждый выбор — одна строка:

| Date & time | Guest name | Cuisine | Menu | Main dish | Submission ID | Duplicate |
|---|---|---|---|---|---|---|
| 2026-10-16 12:00 | Ivanov Ivan Ivanovich | Western | A | Pan Seared Barramundi Fillet | … | |
| 2026-10-16 12:00 | Ivanova Mariya | Thai | B | | … | |

- Лист называется `Responses`, создаётся автоматически с заголовками.
- «Main dish» заполняется, только если в сете есть выбор (Western A/B/C и Thai A). В Thai B блюда общие, поле пустое.
- Кто именно заполнял форму и себе или другому, в таблицу не пишется: в строке только гость, его сет и блюдо.
- Если гость исправил выбор и отправил снова, прежние строки этой заявки заменяются (дублей нет).
- «Duplicate» = `duplicate`, если один и тот же гость есть в нескольких заявках (например, его записал кто-то ещё и он сам).
- «Submission ID» служебный столбец, его можно скрыть.
- Транслитерация упрощённая (ж → zh, х → kh, ц → ts, ч → ch, ш → sh, щ → shch, ю → yu, я → ya, й → y, ъ и ь опускаются).
  Схему можно поменять в начале `Code.gs` (словарь `TRANSLIT`).

## Подключение (один раз)

1. Создайте новую Google Таблицу (sheets.new), назовите «Меню свадьбы».
2. **Расширения → Apps Script**. Удалите весь код в файле `Code.gs`, вставьте содержимое `apps-script/Code.gs`, нажмите значок сохранения.
3. **Начать развёртывание → Новое развёртывание**, шестерёнка → тип **Веб-приложение**:
   - «Выполнять как»: **Я**
   - «У кого есть доступ»: **Все**
   
   Нажмите **Развернуть**, дайте доступ (Google предупредит «приложение не проверено»: **Дополнительно → Перейти на … (небезопасно) → Разрешить**, это ваш собственный скрипт).
4. Скопируйте **URL веб-приложения** (заканчивается на `/exec`). Откройте его в браузере: должно появиться `{"ok":true,"service":"wedding-menu"}`.
5. В Vercel: проект → **Settings → Environment Variables** → имя `VITE_SHEET_WEBHOOK_URL`, значение — этот URL, окружения Production и Preview → **Save**. Затем **Deployments → … → Redeploy**.
6. Проверка: откройте сайт → меню → заполните форму → в таблице появится лист `Responses` со строкой. Тестовые строки потом можно просто удалить (кроме заголовка).

## Если меняете код скрипта

Развернуть → **Управление развёртываниями** → карандаш → «Версия»: **Новая версия** → Развернуть. Адрес `/exec` остаётся прежним.
Если на сайте добавили или переименовали сет, добавьте его id в список `SETS` в начале `Code.gs`.

## Что нужно знать

- Адрес скрипта виден в коде сайта, поэтому отправить ответ технически может любой, кто его найдёт. Скрипт принимает только известные сеты, не больше 10 выборов за раз, обрезает длинный текст и записывает «=…» как обычный текст. После сбора ответов развёртывание можно отключить.
- Данные таблицы наружу скрипт не отдаёт. Гостям доступ к таблице не нужен.
- Если вариант «У кого есть доступ: Все» недоступен, это ограничение корпоративного (Workspace) аккаунта: используйте обычный Gmail.
- Проверка логики скрипта без Google: `node apps-script/test.mjs`.
